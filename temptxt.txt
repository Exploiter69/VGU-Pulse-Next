## 2. Stage 2 Architecture & Security Decisions

1. **Vulnerability Remediation (`tinypool`, `esbuild`, `vite`, `@vitest/mocker`):**
* **Root Cause:** Vitest `^2.1.8` and Vite `^6.0.3` pull in older `tinypool`, `@vitest/mocker`, and `esbuild <=0.24.2` (affected by GHSA-67mh-4wv8-2f99 dev-server request vulnerability and tinypool worker termination issues).
* **Resolution:** Upgraded to **`vite: "^6.2.6"`** and **`vitest: "^3.1.1"`**, plus an explicit `overrides` block in `package.json` pinning `"esbuild": "^0.25.2"`. Run `npm audit` on your Fedora machine after `npm install` to verify against your local advisory database.


2. **Official Cloudflare Vite Plugin + Worker + Static Assets Integration:**
* Configured `@cloudflare/vite-plugin` in `vite.config.ts` paired with `wrangler.jsonc` (`main: "./src/worker/index.ts"`, `assets: { directory: "./dist/client", binding: "ASSETS", not_found_handling: "single-page-application" }`).
* Running `npm run dev` starts Vite with the integrated Cloudflare Worker runtime and local Miniflare D1 bindings on the same port—no separate proxy process required.


3. **Anonymous Capability-Token Security Model (Zero Paid Auth / Zero Account Lock-In):**
* When a student publishes a Pulse Card (`POST /api/cards`) or sends a Handshake Request (`POST /api/handshakes`), the Worker generates a cryptographically random 256-bit capability token (`crypto.getRandomValues`, hex-encoded).
* **Server Storage:** Only the **SHA-256 hash** (`owner_token_hash` or `sender_token_hash`) is stored in Cloudflare D1. The raw secret token is returned **once** in the HTTP `201 Created` response and stored in the creator's browser `localStorage` vault (`vgu_pulse_next_v1_capability_vault`).
* **Protected Operations:** Viewing incoming handshakes for a card, accepting/declining a handshake (`PATCH /api/handshakes/:id`), or checking outgoing handshake status requires presenting the matching capability token in the `Authorization: Bearer <token>` or `X-Pulse-Capability-Token` header.
* **Honest Contact Coordination:** Instead of pretending to verify real identities or running an unmoderated chat server, accepting a handshake reveals an explicit **owner-authored coordination note** (`coordinationNote`, e.g., *"Meet at Central Library 2nd floor table 4 at 3:15 PM, or ping my Telegram @example"*). This note is encrypted/held privately in D1 and **never** returned in public card payloads or OpenGraph metadata—only revealed to a handshake requester whose status is `'accepted'`.


4. **Fail-Closed Turnstile Verification & D1 Sliding-Window Rate Limiting:**
* In `APP_ENV === "production"`, write actions (`POST /api/cards`, `POST /api/handshakes`) require a valid `turnstileToken` verified server-side against `[https://challenges.cloudflare.com/turnstile/v0/siteverify](https://challenges.cloudflare.com/turnstile/v0/siteverify)`. If `TURNSTILE_SECRET_KEY` is missing in production, the Worker **fails closed (`503 Service Unavailable`)** rather than silently bypassing verification.
* In `APP_ENV === "development"` (local `.dev.vars` or test environment), verification accepts Cloudflare's official dummy test key (`1x0000000000000000000000000000000AA`) or local dev bypass so `npm run dev` works offline without a Cloudflare login.
* Rate limiting uses a dedicated D1 `rate_limits` table tracking hashed IP (`SHA-256(ip + salt)`) per action bucket (`create_card`: max 5/hour; `create_handshake`: max 15/hour).


5. **Crawler-Readable OpenGraph Metadata via `HTMLRewriter`:**
* Navigating to `/cards/:id` or `/events/:id` (or `/?card=:id`, `/?event=:id`) passes through the Worker's `HTMLRewriter`, which queries D1 for the public record, escapes all HTML entities, and rewrites `<title>`, `og:title`, `og:description`, `og:url`, `og:image`, and `twitter:*` tags in the initial HTML response before streaming the SPA shell. Private fields (`coordination_note`, token hashes, handshake messages) are never queried or injected into metadata.

### Database Migrations (`migrations/`)

#### `migrations/0001_initial_schema.sql`

```sql
-- Migration 0001: Core Stage 2 relational schema for VGU Pulse Next
-- No fake student records are seeded here.

CREATE TABLE IF NOT EXISTS pulse_cards (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL CHECK (length(title) BETWEEN 10 AND 120),
  category TEXT NOT NULL CHECK (category IN ('hackathon', 'study', 'sports', 'cab_pool', 'project')),
  description TEXT NOT NULL CHECK (length(description) BETWEEN 15 AND 400),
  author_name TEXT NOT NULL CHECK (length(author_name) BETWEEN 2 AND 50),
  author_department TEXT NOT NULL CHECK (length(author_department) BETWEEN 2 AND 60),
  author_year TEXT NOT NULL CHECK (author_year IN ('1st Year', '2nd Year', '3rd Year', '4th Year', 'PG / Research')),
  tags_json TEXT NOT NULL DEFAULT '[]',
  spots_total INTEGER NOT NULL CHECK (spots_total BETWEEN 1 AND 20),
  spots_remaining INTEGER NOT NULL CHECK (spots_remaining >= 0 AND spots_remaining <= spots_total),
  time_window TEXT NOT NULL CHECK (length(time_window) BETWEEN 3 AND 80),
  preferred_handshake_channel TEXT NOT NULL CHECK (preferred_handshake_channel IN ('WhatsApp', 'Telegram', 'In-Person Campus Meet')),
  coordination_note TEXT NOT NULL CHECK (length(coordination_note) BETWEEN 5 AND 200),
  owner_token_hash TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'open' CHECK (status IN ('open', 'filled', 'expired', 'removed')),
  report_count INTEGER NOT NULL DEFAULT 0 CHECK (report_count >= 0),
  created_at TEXT NOT NULL,
  expires_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_pulse_cards_status_created
  ON pulse_cards(status, created_at DESC);

CREATE INDEX IF NOT EXISTS idx_pulse_cards_category_status
  ON pulse_cards(category, status, created_at DESC);

CREATE INDEX IF NOT EXISTS idx_pulse_cards_owner_hash
  ON pulse_cards(owner_token_hash);

CREATE TABLE IF NOT EXISTS campus_events (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL CHECK (length(title) BETWEEN 5 AND 140),
  organizer TEXT NOT NULL CHECK (length(organizer) BETWEEN 2 AND 80),
  category TEXT NOT NULL CHECK (category IN ('Workshop', 'Hackathon', 'Cultural', 'Sports', 'Seminar')),
  date_label TEXT NOT NULL CHECK (length(date_label) BETWEEN 3 AND 40),
  time_label TEXT NOT NULL CHECK (length(time_label) BETWEEN 3 AND 40),
  venue TEXT NOT NULL CHECK (length(venue) BETWEEN 2 AND 100),
  registration_url TEXT,
  verification_source TEXT NOT NULL CHECK (verification_source IN ('Official VGU Link', 'Verified Club Submission', 'Student Submitted (Unverified)')),
  going_count INTEGER NOT NULL DEFAULT 0 CHECK (going_count >= 0),
  looking_for_buddy_count INTEGER NOT NULL DEFAULT 0 CHECK (looking_for_buddy_count >= 0),
  status TEXT NOT NULL DEFAULT 'published' CHECK (status IN ('published', 'archived', 'removed')),
  created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_campus_events_status_created
  ON campus_events(status, created_at DESC);

CREATE TABLE IF NOT EXISTS handshake_requests (
  id TEXT PRIMARY KEY,
  card_id TEXT NOT NULL REFERENCES pulse_cards(id) ON DELETE CASCADE,
  from_student_name TEXT NOT NULL CHECK (length(from_student_name) BETWEEN 2 AND 50),
  from_department TEXT NOT NULL CHECK (length(from_department) BETWEEN 2 AND 60),
  from_year TEXT NOT NULL CHECK (from_year IN ('1st Year', '2nd Year', '3rd Year', '4th Year', 'PG / Research')),
  intro_note TEXT NOT NULL CHECK (length(intro_note) BETWEEN 8 AND 280),
  sender_token_hash TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'accepted', 'declined')),
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_handshakes_card_id
  ON handshake_requests(card_id, created_at DESC);

CREATE INDEX IF NOT EXISTS idx_handshakes_sender_hash
  ON handshake_requests(sender_token_hash, created_at DESC);

CREATE TABLE IF NOT EXISTS rate_limits (
  key TEXT NOT NULL,
  bucket_hour INTEGER NOT NULL,
  hit_count INTEGER NOT NULL DEFAULT 1,
  PRIMARY KEY (key, bucket_hour)
);

```

export type ValidationOutcome<T> = ValidationSuccess<T> | ValidationFailure;

export function containsPublicContactPii(text: string): boolean {
  return PUBLIC_PII_PHONE_REGEX.test(text) || PUBLIC_PII_EMAIL_REGEX.test(text);
}

export function validateCreateCardPayload(
  raw: unknown
): ValidationOutcome<CreatePulseCardInput> {
  if (!raw || typeof raw !== 'object') {
    return {
      valid: false,
      code: 'INVALID_JSON',
      message: 'Request body must be a JSON object.',
    };
  }

  const body = raw as Record<string, unknown>;
  const title = typeof body.title === 'string' ? body.title.trim() : '';
  const category = body.category as PulseCategory;
  const description =
    typeof body.description === 'string' ? body.description.trim() : '';
  const authorName =
    typeof body.authorName === 'string' ? body.authorName.trim() : '';
  const authorDepartment =
    typeof body.authorDepartment === 'string'
      ? body.authorDepartment.trim()
      : '';
  const authorYear = body.authorYear as AcademicYear;
  const timeWindow =
    typeof body.timeWindow === 'string' ? body.timeWindow.trim() : '';
  const preferredHandshakeChannel =
    body.preferredHandshakeChannel as HandshakeChannel;
  const coordinationNote =
    typeof body.coordinationNote === 'string'
      ? body.coordinationNote.trim()
      : '';
  const spotsTotal = Number(body.spotsTotal);
  const turnstileToken =
    typeof body.turnstileToken === 'string' ? body.turnstileToken.trim() : undefined;

  if (title.length < 10 || title.length > 120) {
    return {
      valid: false,
      code: 'INVALID_TITLE',
      field: 'title',
      message: 'Title must be between 10 and 120 characters.',
    };
  }

  if (!ALLOWED_CATEGORIES.includes(category)) {
    return {
      valid: false,
      code: 'INVALID_CATEGORY',
      field: 'category',
      message: 'Select a valid Pulse request category.',
    };
  }

  if (description.length < 15 || description.length > 400) {
    return {
      valid: false,
      code: 'INVALID_DESCRIPTION',
      field: 'description',
      message: 'Description must be between 15 and 400 characters.',
    };
  }

  if (containsPublicContactPii(title) || containsPublicContactPii(description)) {
    return {
      valid: false,
      code: 'PUBLIC_PII_DETECTED',
      field: 'description',
      message:
        'Privacy boundary: Do not include phone numbers or email addresses in the public title or description. Put your meeting/contact details in the private Coordination Note instead.',
    };
  }

  if (authorName.length < 2 || authorName.length > 50) {
    return {
      valid: false,
      code: 'INVALID_AUTHOR_NAME',

      message: 'Author name must be between 2 and 50 characters.',

      valid: false,

export interface AttendanceInput {
  attended: number;
  totalHeld: number;
  targetPercentage: number;
  simulateAttendNext?: number;
  simulateMissNext?: number;
}

export interface AttendanceResult {
  isValid: boolean;
  error?: string;
  currentPercentage: number;
  projectedPercentage: number;
  status: 'safe' | 'warning' | 'deficit';
  classesCanSkipSafely: number;
  classesMustAttendToRecover: number;
  summaryText: string;
}

export function calculateAttendance(input: AttendanceInput): AttendanceResult {
  const {
    attended,
    totalHeld,
    targetPercentage,
    simulateAttendNext = 0,
    simulateMissNext = 0,
  } = input;

  if (
    !Number.isFinite(attended) ||
    !Number.isFinite(totalHeld) ||
    !Number.isFinite(targetPercentage)
  ) {
    return {
      isValid: false,
      error: 'Please enter valid numbers.',
      currentPercentage: 0,
      projectedPercentage: 0,
      status: 'deficit',
      classesCanSkipSafely: 0,
      classesMustAttendToRecover: 0,
      summaryText: 'Invalid input.',
    };
  }

  if (attended < 0 || totalHeld < 0 || simulateAttendNext < 0 || simulateMissNext < 0) {
    return {
      isValid: false,
      error: 'Class counts cannot be negative.',
      currentPercentage: 0,
      projectedPercentage: 0,
      status: 'deficit',
      classesCanSkipSafely: 0,
      classesMustAttendToRecover: 0,
      summaryText: 'Class counts cannot be negative.',
    };
  }

  if (attended > totalHeld) {
    return {
      isValid: false,
      error: 'Attended classes cannot exceed total classes held.',
      currentPercentage: 0,
      projectedPercentage: 0,
      status: 'deficit',
      classesCanSkipSafely: 0,
      classesMustAttendToRecover: 0,
      summaryText: 'Check inputs: Attended > Held.',
    };
  }

  if (targetPercentage <= 0 || targetPercentage >= 100) {
    return {
      isValid: false,
      error: 'Target threshold must be between 1% and 99%.',
      currentPercentage: 0,
      projectedPercentage: 0,
      status: 'deficit',
      classesCanSkipSafely: 0,
      classesMustAttendToRecover: 0,
      summaryText: 'Target threshold must be between 1% and 99%.',
    };
  }

  if (totalHeld === 0) {
    return {
      isValid: true,
      currentPercentage: 100,
      projectedPercentage: 100,
      status: 'safe',
      classesCanSkipSafely: 0,
      classesMustAttendToRecover: 0,
      summaryText: 'No classes held yet. Enter your current lecture counts.',
    };
  }

  const targetRatio = targetPercentage / 100;
  const currentPercentage = Number(((attended / totalHeld) * 100).toFixed(2));

  const projectedAttended = attended + simulateAttendNext;
  const projectedTotal = totalHeld + simulateAttendNext + simulateMissNext;
  const projectedPercentage =
    projectedTotal > 0
      ? Number(((projectedAttended / projectedTotal) * 100).toFixed(2))
      : currentPercentage;

  let classesCanSkipSafely = 0;
  let classesMustAttendToRecover = 0;

  if (projectedPercentage >= targetPercentage) {
    classesCanSkipSafely = Math.max(
      0,
      Math.floor(projectedAttended / targetRatio - projectedTotal)
    );
  } else {
    classesMustAttendToRecover = Math.max(
      1,
      Math.ceil(
        (targetRatio * projectedTotal - projectedAttended) / (1 - targetRatio)
      )
    );
  }

  const status: 'safe' | 'warning' | 'deficit' =
    projectedPercentage >= targetPercentage + 3
      ? 'safe'
      : projectedPercentage >= targetPercentage
      ? 'warning'
      : 'deficit';

  const summaryText =
    projectedPercentage >= targetPercentage
      ? classesCanSkipSafely > 0
        ? `You can safely miss ${classesCanSkipSafely} upcoming ${
            classesCanSkipSafely === 1 ? 'class' : 'classes'
          } and stay at or above ${targetPercentage}%.`
        : `You are right on the ${targetPercentage}% boundary. Attending the next class builds a buffer.`
      : `Attend the next ${classesMustAttendToRecover} consecutive ${
          classesMustAttendToRecover === 1 ? 'class' : 'classes'
        } to reach ${targetPercentage}%.`;

  return {
    isValid: true,
    currentPercentage,
    projectedPercentage,
    status,
    classesCanSkipSafely,
    classesMustAttendToRecover,
    summaryText,
  };
}

import { CourseGradeRow } from '../types/domain';

export const DEFAULT_GRADE_SCALE: Record<string, number> = {
  O: 10,
  'A+': 9,
  A: 8,
  'B+': 7,
  B: 6,
  C: 5,
  P: 4,
  F: 0,
};

export interface SgpaCalculationResult {
  isValid: boolean;
  error?: string;
  totalCredits: number;
  weightedPoints: number;
  sgpa: number;
  projectedCgpa: number | null;
}

export function calculateSgpaAndCgpa(
  courses: CourseGradeRow[],
  gradeScale: Record<string, number> = DEFAULT_GRADE_SCALE,
  priorCgpa?: number,
  priorTotalCredits?: number
): SgpaCalculationResult {
  if (!courses.length) {
    return {
      isValid: false,
      error: 'Add at least one subject to calculate SGPA.',
      totalCredits: 0,
      weightedPoints: 0,
      sgpa: 0,
      projectedCgpa: null,
    };
  }

  let totalCredits = 0;
  let weightedPoints = 0;

  for (const row of courses) {
    if (!Number.isFinite(row.credits) || row.credits <= 0) {
      return {
        isValid: false,
        error: `Credits for "${row.name || 'unnamed subject'}" must be greater than 0.`,
        totalCredits: 0,
        weightedPoints: 0,
        sgpa: 0,
        projectedCgpa: null,
      };
    }
    const gp = gradeScale[row.gradeLetter];
    if (gp === undefined) {
      return {
        isValid: false,
        error: `Unknown grade "${row.gradeLetter}".`,
        totalCredits: 0,
        weightedPoints: 0,
        sgpa: 0,
        projectedCgpa: null,
      };
    }
    totalCredits += row.credits;
    weightedPoints += row.credits * gp;
  }

  const sgpa = Number((weightedPoints / totalCredits).toFixed(2));

  let projectedCgpa: number | null = null;
  if (
    priorCgpa !== undefined &&
    priorTotalCredits !== undefined &&
    Number.isFinite(priorCgpa) &&
    Number.isFinite(priorTotalCredits) &&
    priorTotalCredits > 0 &&
    priorCgpa >= 0 &&
    priorCgpa <= 10
  ) {
    const combinedPoints = priorCgpa * priorTotalCredits + weightedPoints;
    const combinedCredits = priorTotalCredits + totalCredits;
    projectedCgpa = Number((combinedPoints / combinedCredits).toFixed(2));
  }

  return {
    isValid: true,
    totalCredits,
    weightedPoints,
    sgpa,
    projectedCgpa,
  };
}

import { CapabilityVault } from '../types/domain';

const STORAGE_PREFIX = 'vgu_pulse_next_v1_';
const VAULT_KEY = 'capability_vault';

export function loadLocalState<T>(key: string, fallback: T): T {
  try {
    const raw = window.localStorage.getItem(`${STORAGE_PREFIX}${key}`);
    if (!raw) return fallback;
    return JSON.parse(raw) as T;
  } catch {
    return fallback;
  }
}

export function saveLocalState<T>(key: string, value: T): void {
  try {
    window.localStorage.setItem(`${STORAGE_PREFIX}${key}`, JSON.stringify(value));
  } catch {
    // Graceful no-op if storage quota or private mode blocks write
  }
}

export function loadCapabilityVault(): CapabilityVault {
  return loadLocalState<CapabilityVault>(VAULT_KEY, {
    ownedCards: {},
    sentHandshakes: {},
  });
}

export function saveCardOwnerToken(cardId: string, rawToken: string): CapabilityVault {
  const vault = loadCapabilityVault();
  const updated: CapabilityVault = {
    ...vault,
    ownedCards: { ...vault.ownedCards, [cardId]: rawToken },
  };
  saveLocalState(VAULT_KEY, updated);
  return updated;
}

}

export function clearAllLocalPulseData(): void {
  try {
    const keysToRemove: string[] = [];
    for (let i = 0; i < window.localStorage.length; i++) {
      const k = window.localStorage.key(i);
      if (k && k.startsWith(STORAGE_PREFIX)) {
        keysToRemove.push(k);

/**
 * Generates a cryptographically strong 256-bit (32-byte) capability token in hex format.
 * Only its SHA-256 hash is ever persisted in Cloudflare D1.
 */
export function generateCapabilityToken(): string {
  const bytes = new Uint8Array(32);
  crypto.getRandomValues(bytes);
  return Array.from(bytes, (b) => b.toString(16).padStart(2, '0')).join('');
}

export async function sha256Hex(input: string): Promise<string> {
  const encoded = new TextEncoder().encode(input);
  const digest = await crypto.subtle.digest('SHA-256', encoded);
  return Array.from(new Uint8Array(digest), (b) =>
    b.toString(16).padStart(2, '0')
  ).join('');
}

export function generateRecordId(prefix: string): string {
  const bytes = new Uint8Array(8);
  crypto.getRandomValues(bytes);
  const randHex = Array.from(bytes, (b) => b.toString(16).padStart(2, '0')).join('');
  return `${prefix}-${randHex}`;
}

export interface TurnstileConfig {
  appEnv: string;
  secretKey?: string;
}

export interface TurnstileVerifyResult {
  ok: boolean;
  code?: string;
  message?: string;
}

const CLOUDFLARE_DUMMY_TEST_SECRET = '1x0000000000000000000000000000000AA';
const LOCAL_DEV_BYPASS_TOKEN = 'LOCAL_DEV_TURNSTILE_BYPASS';

export async function verifyTurnstileToken(
  token: string | undefined,
  remoteIp: string | null,
  config: TurnstileConfig
): Promise<TurnstileVerifyResult> {
  const isProd = config.appEnv === 'production';

  // Fail closed in production if TURNSTILE_SECRET_KEY is not configured
  if (isProd && (!config.secretKey || config.secretKey === CLOUDFLARE_DUMMY_TEST_SECRET)) {
    return {
      ok: false,
      code: 'VERIFICATION_MISCONFIGURED',
      message:
        'Server security check is not configured for production. Publishing is temporarily disabled.',
    };
  }

  // In non-production (development/test), allow local bypass token or dummy secret without outbound network dependency
  if (!isProd) {
    if (
      !config.secretKey ||
      config.secretKey === CLOUDFLARE_DUMMY_TEST_SECRET ||
      token === LOCAL_DEV_BYPASS_TOKEN
    ) {
      if (token === 'FORCE_TURNSTILE_FAIL') {
        return {
          ok: false,
          code: 'TURNSTILE_REJECTED',
          message: 'Verification challenge failed.',
        };
      }
      return { ok: true };
    }
  }

  if (!token || token.trim().length === 0) {
    return {
      ok: false,
      code: 'TURNSTILE_REQUIRED',
      message: 'Please complete the anti-spam verification check before submitting.',
    };
  }

  try {
    const formData = new URLSearchParams();
    formData.set('secret', config.secretKey!);
    formData.set('response', token);
    if (remoteIp) {
      formData.set('remoteip', remoteIp);
    }

    const res = await fetch(
      'https://challenges.cloudflare.com/turnstile/v0/siteverify',
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
        body: formData.toString(),
      }
    );

    if (!res.ok) {
      return {
        ok: false,
        code: 'TURNSTILE_UPSTREAM_ERROR',
        message: 'Could not verify anti-spam challenge. Please retry.',
      };
    }

    const outcome = (await res.json()) as { success?: boolean };
    if (!outcome.success) {
      return {
        ok: false,
        code: 'TURNSTILE_REJECTED',
        message: 'Anti-spam verification expired or failed. Please try again.',
      };
    }

    return { ok: true };
  } catch {
    return {
      ok: false,
      code: 'TURNSTILE_NETWORK_ERROR',
      message: 'Verification service unreachable.',
    };
  }
}

import { sha256Hex } from './crypto';

export interface RateLimitCheck {
  allowed: boolean;
  currentHits: number;
  limit: number;
}

export async function checkAndIncrementRateLimit(
  db: D1Database,
  clientIp: string,
  salt: string,
  action: 'create_card' | 'create_handshake' | 'report_card',
  maxHitsPerHour: number
): Promise<RateLimitCheck> {
  const bucketHour = Math.floor(Date.now() / 3_600_000);
  const ipHash = await sha256Hex(`${clientIp}:${salt}:${action}`);
  const key = `${action}:${ipHash}`;

  await db
    .prepare(
      `INSERT INTO rate_limits (key, bucket_hour, hit_count)
       VALUES (?1, ?2, 1)
       ON CONFLICT(key, bucket_hour)
       DO UPDATE SET hit_count = hit_count + 1`
    )
    .bind(key, bucketHour)
    .run();

  const row = await db
    .prepare(
      `SELECT hit_count FROM rate_limits WHERE key = ?1 AND bucket_hour = ?2`
    )
    .bind(key, bucketHour)
    .first<{ hit_count: number }>();

  const currentHits = row?.hit_count ?? 1;
  return {
    allowed: currentHits <= maxHitsPerHour,
    currentHits,
    limit: maxHitsPerHour,
  };
}

export async function createHandshakeRecord(
  db: D1Database,
  input: CreateHandshakeInput
): Promise<
  | { ok: true; handshake: HandshakeRequest; senderCapabilityToken: string }
  | { ok: false; code: string; message: string; status: number }
> {
  const cardRow = await db
    .prepare(`SELECT * FROM pulse_cards WHERE id = ?1`)
    .bind(input.cardId)
    .first<D1PulseCardRow>();

  if (!cardRow || cardRow.status === 'removed' || cardRow.report_count >= 5) {
    return {
      ok: false,
      code: 'CARD_NOT_FOUND',
      message: 'The requested Pulse card does not exist or is no longer active.',
      status: 404,
    };
  }

  if (cardRow.status !== 'open' || cardRow.spots_remaining <= 0) {
    return {
      ok: false,
      code: 'CARD_FULL',
      message: 'All spots on this request card have already been filled.',
      status: 409,
    };
  }

  const id = generateRecordId('hs');
  const rawSenderToken = generateCapabilityToken();
  const senderTokenHash = await sha256Hex(rawSenderToken);
  const nowIso = new Date().toISOString();

  await db
    .prepare(
      `INSERT INTO handshake_requests (
        id, card_id, from_student_name, from_department, from_year,
        intro_note, sender_token_hash, status, created_at, updated_at
      ) VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7, 'pending', ?8, ?8)`
    )
    .bind(
      id,
      input.cardId,
      input.fromStudentName,
      input.fromDepartment,
      input.fromYear,
      input.introNote,
      senderTokenHash,
      nowIso
    )
    .run();

  const joined = await db
    .prepare(
      `SELECT
        h.*,
        c.title AS card_title,
        c.coordination_note AS card_coordination_note,
        c.preferred_handshake_channel AS card_channel,
        c.owner_token_hash AS card_owner_hash
       FROM handshake_requests h
       JOIN pulse_cards c ON c.id = h.card_id
       WHERE h.id = ?1`
    )
    .bind(id)
    .first<D1HandshakeJoinedRow>();

  if (!joined) {
    throw new Error('Failed to load created handshake.');
  }

  return {
    ok: true,
    handshake: mapHandshakeRow(joined, 'outgoing'),
    senderCapabilityToken: rawSenderToken,
  };
}

export async function listAuthorizedHandshakes(
  db: D1Database,
  rawOwnerTokens: string[],
  rawSenderTokens: string[]
): Promise<HandshakeRequest[]> {
  const ownerHashes = await Promise.all(
    rawOwnerTokens.slice(0, 30).map((t) => sha256Hex(t))
  );
  const senderHashes = await Promise.all(
    rawSenderTokens.slice(0, 50).map((t) => sha256Hex(t))
  );

  const results: HandshakeRequest[] = [];

  if (ownerHashes.length > 0) {
    const placeholders = ownerHashes.map((_, i) => `?${i + 1}`).join(', ');
    const rows = await db
      .prepare(
        `SELECT
          h.*,
          c.title AS card_title,
          c.coordination_note AS card_coordination_note,
          c.preferred_handshake_channel AS card_channel,
          c.owner_token_hash AS card_owner_hash
         FROM handshake_requests h
         JOIN pulse_cards c ON c.id = h.card_id
         WHERE c.owner_token_hash IN (${placeholders})
         ORDER BY h.created_at DESC`
      )
      .bind(...ownerHashes)
      .all<D1HandshakeJoinedRow>();

    for (const r of rows.results ?? []) {
      results.push(mapHandshakeRow(r, 'incoming'));
    }
  }

  if (senderHashes.length > 0) {
    const placeholders = senderHashes.map((_, i) => `?${i + 1}`).join(', ');
    const rows = await db
      .prepare(
        `SELECT
          h.*,
          c.title AS card_title,
          c.coordination_note AS card_coordination_note,
          c.preferred_handshake_channel AS card_channel,
          c.owner_token_hash AS card_owner_hash
         FROM handshake_requests h
         JOIN pulse_cards c ON c.id = h.card_id
         WHERE h.sender_token_hash IN (${placeholders})
         ORDER BY h.created_at DESC`
      )
      .bind(...senderHashes)
      .all<D1HandshakeJoinedRow>();

    for (const r of rows.results ?? []) {
      // Avoid duplicate if same browser owns card and sent test handshake
      if (!results.some((existing) => existing.id === r.id)) {
        results.push(mapHandshakeRow(r, 'outgoing'));
      }
    }
  }

  return results;
}

export async function updateHandshakeDecision(
  db: D1Database,
  handshakeId: string,
  rawOwnerToken: string,
  newStatus: 'accepted' | 'declined'

  | { ok: false; code: string; message: string; status: number }
> {
  const joined = await db
    .prepare(
      `SELECT
        h.*,
        c.title AS card_title,
        c.coordination_note AS card_coordination_note,
        c.preferred_handshake_channel AS card_channel,
        c.owner_token_hash AS card_owner_hash
       FROM handshake_requests h
       JOIN pulse_cards c ON c.id = h.card_id
       WHERE h.id = ?1`
    )
    .bind(handshakeId)
    .first<D1HandshakeJoinedRow>();

  if (!joined) {
    return {
      ok: false,
      code: 'HANDSHAKE_NOT_FOUND',
      message: 'Handshake request not found.',
      status: 404,
    };
  }

  const callerHash = await sha256Hex(rawOwnerToken);
  if (callerHash !== joined.card_owner_hash) {
    return {
      ok: false,
      code: 'FORBIDDEN_CAPABILITY',
      message: 'Invalid or unauthorized card-owner capability token.',
      status: 403,
    };
  }

  const nowIso = new Date().toISOString();
  const previousStatus = joined.status;

  await db
    .prepare(
      `UPDATE handshake_requests
       SET status = ?2, updated_at = ?3
       WHERE id = ?1`
    )
    .bind(handshakeId, newStatus, nowIso)
    .run();

  if (previousStatus !== 'accepted' && newStatus === 'accepted') {
    await db
      .prepare(
        `UPDATE pulse_cards
         SET spots_remaining = MAX(0, spots_remaining - 1),
             status = CASE WHEN spots_remaining - 1 <= 0 THEN 'filled' ELSE status END
         WHERE id = ?1`
      )
      .bind(joined.card_id)
      .run();
  }

  const updatedRow: D1HandshakeJoinedRow = {
    ...joined,
    status: newStatus,
    updated_at: nowIso,
  };

  return {
    ok: true,
    handshake: mapHandshakeRow(updatedRow, 'incoming'),
  };
}

export interface OgMetadataSpec {
  title: string;
  description: string;
  canonicalUrl: string;
  imageUrl: string;
  httpStatus?: number;
}

export function escapeHtmlAttribute(value: string): string {
  return value
    .replace(/&/g, '&amp;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#39;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;');
}

export function buildCardOgMetadata(
  card: PulseCard | null,
  origin: string,
  requestedId: string
): OgMetadataSpec {
  const cleanOrigin = origin.replace(/\/$/, '');
  const imageUrl = `${cleanOrigin}/og-default.svg`;
  const canonicalUrl = `${cleanOrigin}/cards/${encodeURIComponent(requestedId)}`;

  if (!card || card.status === 'removed' || card.status === 'expired') {
    return {
      title: 'Request Unavailable — VGU Pulse',
      description:
        'This student collaboration request has expired or is no longer available on VGU Pulse.',
      canonicalUrl,
      imageUrl,
      httpStatus: 404,
    };
  }

  return {
    title: `${card.title} — VGU Pulse (${card.spotsRemaining}/${card.spotsTotal} spots open)`,
    description: `${card.category.toUpperCase()} • ${card.timeWindow} • Posted by ${card.authorName} (${card.authorDepartment}, ${card.authorYear}). ${card.description}`,
    canonicalUrl,
    imageUrl,
    httpStatus: 200,
  };
}

export function buildEventOgMetadata(

  origin: string,
  requestedId: string
): OgMetadataSpec {
  const cleanOrigin = origin.replace(/\/$/, '');

    canonicalUrl,
    imageUrl,
    httpStatus: 200,
  };
}

export function rewriteHtmlWithOgMetadata(
  baseHtmlResponse: Response,
  meta: OgMetadataSpec
): Response {
  const safeTitle = escapeHtmlAttribute(meta.title);
  const safeDesc = escapeHtmlAttribute(meta.description);
  const safeUrl = escapeHtmlAttribute(meta.canonicalUrl);
  const safeImage = escapeHtmlAttribute(meta.imageUrl);

  const transformed = new HTMLRewriter()
    .on('title', {
      element(el) {
        el.setInnerContent(meta.title);
      },
    })
    .on('meta[name="description"]', {
      element(el) {
        el.setAttribute('content', safeDesc);
      },
    })
    .on('meta[property="og:title"]', {
      element(el) {
        el.setAttribute('content', safeTitle);
      },
    })
    .on('meta[property="og:description"]', {
      element(el) {
        el.setAttribute('content', safeDesc);
      },
    })
    .on('meta[property="og:url"]', {
      element(el) {
        el.setAttribute('content', safeUrl);
      },
    })
    .on('meta[property="og:image"]', {
      element(el) {
        el.setAttribute('content', safeImage);
      },
    })
    .on('meta[name="twitter:title"]', {
      element(el) {
        el.setAttribute('content', safeTitle);
      },
    })
    .on('meta[name="twitter:description"]', {
      element(el) {
        el.setAttribute('content', safeDesc);
      },
    })
    .on('meta[name="twitter:image"]', {
      element(el) {
        el.setAttribute('content', safeImage);
      },
    })
    .on('link[rel="canonical"]', {
      element(el) {
        el.setAttribute('href', safeUrl);
      },
    })
    .transform(baseHtmlResponse);

  const headers = new Headers(transformed.headers);
  headers.set('Content-Type', 'text/html; charset=utf-8');

  return new Response(transformed.body, {
    status: meta.httpStatus ?? 200,
    headers,
  });
}

const MAX_BODY_BYTES = 16_384; // 16 KB strict payload ceiling

function jsonResponse(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: {
      'Content-Type': 'application/json; charset=utf-8',
      'X-Content-Type-Options': 'nosniff',
      'Cache-Control': 'no-store',
    },
  });
}

function errorResponse(
  code: string,
  message: string,
  status = 400,
  field?: string
): Response {
  return jsonResponse(
    {
      ok: false,
      error: {
        code,
        message,
        ...(field ? { field } : {}),
      },
    },
    status
  );
}

async function readBoundedJson(
  request: Request
): Promise<
  | { ok: true; data: unknown }
  | { ok: false; response: Response }
> {
  const contentLength = Number(request.headers.get('content-length') || '0');
  if (contentLength > MAX_BODY_BYTES) {
    return {
      ok: false,
      response: errorResponse(
        'PAYLOAD_TOO_LARGE',
        'Request payload exceeds the 16 KB size limit.',
        413
      ),
    };
  }

  const rawText = await request.text();
  if (new TextEncoder().encode(rawText).byteLength > MAX_BODY_BYTES) {
    return {
      ok: false,
      response: errorResponse(
        'PAYLOAD_TOO_LARGE',
        'Request payload exceeds the 16 KB size limit.',
        413
      ),
    };
  }

  try {
    return { ok: true, data: JSON.parse(rawText) };
  } catch {
    return {
      ok: false,
      response: errorResponse(
        'MALFORMED_JSON',
        'Request body contains malformed JSON.',
        400
      ),
    };
  }
}

function extractBearerOrCapabilityToken(request: Request): string | null {
  const authHeader = request.headers.get('Authorization');
  if (authHeader && authHeader.startsWith('Bearer ')) {
    return authHeader.slice(7).trim();
  }
  const customHeader = request.headers.get('X-Pulse-Capability-Token');
  return customHeader ? customHeader.trim() : null;
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);
    const { pathname, searchParams } = url;
    const method = request.method.toUpperCase();
    const appEnv = env.APP_ENV || 'development';
    const clientIp =
      request.headers.get('CF-Connecting-IP') ||
      request.headers.get('X-Forwarded-For') ||

          healthy ? 200 : 503

      // GET /api/cards

        return jsonResponse({ ok: true, cards });

      // POST /api/cards
      if (pathname === '/api/cards' && method === 'POST') {

        if (!parsed.ok) return parsed.response;

        const validation = validateCreateCardPayload(parsed.data);

          env.DB,
          clientIp,
          salt,
          'create_card',
          5

          return errorResponse(
            'RATE_LIMITED',
            'Rate limit reached: You can publish at most 5 request cards per hour.',
            429
          );
        }

        const created = await createCardRecord(env.DB, validation.data);
        return jsonResponse(
          {
            ok: true,
            card: created.card,
            ownerCapabilityToken: created.ownerCapabilityToken,
          },
          201
        );
      }

      // GET /api/cards/:id or POST /api/cards/:id/report
      const cardMatch = pathname.match(/^\/api\/cards\/([^/]+)(\/report)?$/);
      if (cardMatch) {
        const cardId = decodeURIComponent(cardMatch[1]);
        const isReport = cardMatch[2] === '/report';

        if (!isReport && method === 'GET') {
          const card = await getPublicCardById(env.DB, cardId);
          if (!card) {
            return errorResponse(
              'CARD_NOT_FOUND',
              'Pulse request card not found.',
              404
            );
          }
          return jsonResponse({ ok: true, card });
        }

        if (isReport && method === 'POST') {
          const rate = await checkAndIncrementRateLimit(
            env.DB,
            clientIp,
            salt,
            'report_card',
            10
          );
          if (!rate.allowed) {
            return errorResponse(
              'RATE_LIMITED',
              'Too many report actions from this connection.',
              429
            );
          }
          const updated = await incrementCardReportCount(env.DB, cardId);
          if (!updated) {
            return errorResponse('CARD_NOT_FOUND', 'Card not found.', 404);
          }
          return jsonResponse({ ok: true });
        }
      }

      if (pathname === '/api/events' && method === 'GET') {
        const events = await listPublicEvents(env.DB);
        return jsonResponse({ ok: true, events });

      const eventMatch = pathname.match(/^\/api\/events\/([^/]+)(\/buddy)?$/);
      if (eventMatch) {
        const eventId = decodeURIComponent(eventMatch[1]);
        const isBuddyAction = eventMatch[2] === '/buddy';

          const event = await getPublicEventById(env.DB, eventId);
          if (!event) {

              'EVENT_NOT_FOUND',
              'Campus event not found.',
              404

          return jsonResponse({ ok: true, event });

          if (!parsed.ok) return parsed.response;
          const body = parsed.data as Record<string, unknown>;
          const direction = body?.direction === 'leave' ? 'leave' : 'join';

            return errorResponse(

              'Campus event not found.',

        const parsed = await readBoundedJson(request);
        if (!parsed.ok) return parsed.response;

          env.DB,
          clientIp,
          salt,

          return errorResponse(created.code, created.message, created.status);

        return jsonResponse(

            ok: true,
            handshake: created.handshake,
            senderCapabilityToken: created.senderCapabilityToken,
          },
          201
        );
      }

      // POST /api/handshakes/sync (Protected by capability tokens in body)
      if (pathname === '/api/handshakes/sync' && method === 'POST') {
        const parsed = await readBoundedJson(request);
        if (!parsed.ok) return parsed.response;

        const body = (parsed.data || {}) as Record<string, unknown>;
        const ownerTokens = Array.isArray(body.ownerTokens)
          ? body.ownerTokens.filter((t): t is string => typeof t === 'string')
          : [];
        const senderTokens = Array.isArray(body.senderTokens)
          ? body.senderTokens.filter((t): t is string => typeof t === 'string')
          : [];

        const handshakes = await listAuthorizedHandshakes(
          env.DB,
          ownerTokens,
          senderTokens
        );
        return jsonResponse({ ok: true, handshakes });
      }

      // PATCH /api/handshakes/:id (Accept / Decline protected by owner capability token)
      const handshakePatchMatch = pathname.match(/^\/api\/handshakes\/([^/]+)$/);
      if (handshakePatchMatch && method === 'PATCH') {
        const handshakeId = decodeURIComponent(handshakePatchMatch[1]);
        const token = extractBearerOrCapabilityToken(request);
        if (!token) {
          return errorResponse(
            'UNAUTHORIZED',
            'Missing card owner capability token.',
            401
          );
        }

        const parsed = await readBoundedJson(request);
        if (!parsed.ok) return parsed.response;
        const body = (parsed.data || {}) as Record<string, unknown>;
        const status = body.status;

        if (status !== 'accepted' && status !== 'declined') {
          return errorResponse(
            'INVALID_STATUS',
            'Handshake decision must be "accepted" or "declined".',
            400,
            'status'
          );
        }

        const outcome = await updateHandshakeDecision(
          env.DB,
          handshakeId,
          token,
          status
        );
        if (!outcome.ok) {
          return errorResponse(outcome.code, outcome.message, outcome.status);
        }

        return jsonResponse({ ok: true, handshake: outcome.handshake });
      }

      if (pathname.startsWith('/api/')) {
        return errorResponse('NOT_FOUND', 'API endpoint not found.', 404);
      }

      // =========================================================
      // 2. SHAREABLE PUBLIC URLs WITH CRAWLER-READABLE OPENGRAPH
      // =========================================================
      const shareCardRoute = pathname.match(/^\/cards\/([^/]+)\/?$/);
      const shareEventRoute = pathname.match(/^\/events\/([^/]+)\/?$/);
      const queryCardId = searchParams.get('card');
      const queryEventId = searchParams.get('event');

      const targetCardId = shareCardRoute
        ? decodeURIComponent(shareCardRoute[1])
        : queryCardId;
      const targetEventId = shareEventRoute
        ? decodeURIComponent(shareEventRoute[1])
        : queryEventId;

      if (method === 'GET' && (targetCardId || targetEventId)) {
        const publicOrigin = env.PUBLIC_ORIGIN || url.origin;
        const indexReq = new Request(new URL('/index.html', url.origin), request);
        const baseHtmlRes = env.ASSETS
          ? await env.ASSETS.fetch(indexReq)
          : new Response(
              `<!DOCTYPE html><html><head><title>VGU Pulse</title><meta name="description" content=""/><meta property="og:title" content=""/><meta property="og:description" content=""/><meta property="og:url" content=""/><meta property="og:image" content=""/><meta name="twitter:title" content=""/><meta name="twitter:description" content=""/><meta name="twitter:image" content=""/><link rel="canonical" href=""/></head><body><div id="root"></div></body></html>`,
              { headers: { 'Content-Type': 'text/html; charset=utf-8' } }
            );

        if (targetCardId) {
          const card = await getPublicCardById(env.DB, targetCardId);
          const meta = buildCardOgMetadata(card, publicOrigin, targetCardId);
          return rewriteHtmlWithOgMetadata(baseHtmlRes, meta);
        }

        if (targetEventId) {
          const event = await getPublicEventById(env.DB, targetEventId);
          const meta = buildEventOgMetadata(event, publicOrigin, targetEventId);
          return rewriteHtmlWithOgMetadata(baseHtmlRes, meta);
        }
      }

      // Fallback to static SPA assets
      if (env.ASSETS) {
        return env.ASSETS.fetch(request);
      }

      return new Response('VGU Pulse Worker running.', { status: 200 });
    } catch {
      return errorResponse(
        'INTERNAL_SERVER_ERROR',
        'An unexpected server error occurred.',
        500
      );
    }
  },
};

                      maxLength={200}

 * capability-token hashing, rate limiting, Turnstile fail-closed behavior,
 * and private-field isolation in Node/Vitest without external binaries.
 */
function createInMemoryD1Mock(): D1Database {
  const cards = new Map<string, Record<string, unknown>>();
  const events = new Map<string, Record<string, unknown>>();
  const handshakes = new Map<string, Record<string, unknown>>();
  const rateLimits = new Map<string, number>();

  // Seed 1 verified event matching 0002_seed_verified_events.sql
  events.set('evt-academic-abc-verification', {
    id: 'evt-academic-abc-verification',
    title: 'UGC Academic Bank of Credits (ABC ID) Verification',
    organizer: 'Academic Administration Reference',
    category: 'Seminar',
    date_label: 'Ongoing Semester Requirement',
    time_label: 'Portal Open 24x7',
    venue: 'Online via abc.gov.in',
    registration_url: 'https://www.abc.gov.in',
    verification_source: 'Official VGU Link',
    going_count: 2,
    looking_for_buddy_count: 1,
    status: 'published',
    created_at: '2026-10-15T00:00:00.000Z',
  });

  const prepare = (sql: string) => {
    let boundArgs: unknown[] = [];
    const stmt = {
      bind(...args: unknown[]) {
        boundArgs = args;
        return stmt;
      },
      async first<T>(): Promise<T | null> {
        if (sql.includes('SELECT 1 AS alive')) {
          return { alive: 1 } as unknown as T;
        }
        if (sql.includes('FROM rate_limits')) {
          const key = `${boundArgs[0]}:${boundArgs[1]}`;
          return { hit_count: rateLimits.get(key) ?? 1 } as unknown as T;
        }
        if (sql.includes('FROM pulse_cards') && sql.includes('WHERE id = ?1')) {
          const row = cards.get(String(boundArgs[0]));
          return (row ?? null) as unknown as T;
        }
        if (sql.includes('FROM campus_events') && sql.includes('WHERE id = ?1')) {
          const row = events.get(String(boundArgs[0]));
          return (row ?? null) as unknown as T;
        }
        if (sql.includes('FROM handshake_requests h') && sql.includes('WHERE h.id = ?1')) {
          const hs = handshakes.get(String(boundArgs[0]));
          if (!hs) return null;
          const card = cards.get(String(hs.card_id));
          if (!card) return null;
          return {
            ...hs,
            card_title: card.title,
            card_coordination_note: card.coordination_note,
            card_channel: card.preferred_handshake_channel,
            card_owner_hash: card.owner_token_hash,
          } as unknown as T;
        }
        return null;
      },
      async all<T>(): Promise<{ results: T[] }> {
        if (sql.includes('FROM pulse_cards')) {
          const list = Array.from(cards.values()).filter(
            (c) => c.status !== 'removed' && Number(c.report_count) < 5
          );
          return { results: list as unknown as T[] };
        }
        if (sql.includes('FROM campus_events')) {
          return {
            results: Array.from(events.values()) as unknown as T[],
          };
        }
        if (sql.includes('FROM handshake_requests h')) {
          const hashSet = new Set(boundArgs.map(String));
          const isOwnerQuery = sql.includes('c.owner_token_hash IN');
          const matched: unknown[] = [];

          for (const hs of handshakes.values()) {
            const card = cards.get(String(hs.card_id));
            if (!card) continue;
            const targetHash = isOwnerQuery
              ? String(card.owner_token_hash)
              : String(hs.sender_token_hash);
            if (hashSet.has(targetHash)) {
              matched.push({
                ...hs,
                card_title: card.title,
                card_coordination_note: card.coordination_note,
                card_channel: card.preferred_handshake_channel,
                card_owner_hash: card.owner_token_hash,
              });
            }
          }
          return { results: matched as T[] };
        }
        return { results: [] };
      },
      async run() {
        if (sql.includes('INSERT INTO rate_limits')) {
          const key = `${boundArgs[0]}:${boundArgs[1]}`;
          rateLimits.set(key, (rateLimits.get(key) ?? 0) + 1);
          return { meta: { changes: 1 } };
        }
        if (sql.includes('INSERT INTO pulse_cards')) {
          const id = String(boundArgs[0]);
          cards.set(id, {
            id,
            title: boundArgs[1],
            category: boundArgs[2],
            description: boundArgs[3],
            author_name: boundArgs[4],
            author_department: boundArgs[5],
            author_year: boundArgs[6],
            tags_json: boundArgs[7],
            spots_total: boundArgs[8],
            spots_remaining: boundArgs[9],
            time_window: boundArgs[10],
            preferred_handshake_channel: boundArgs[11],
            coordination_note: boundArgs[12],
            owner_token_hash: boundArgs[13],
            status: 'open',
            report_count: 0,
            created_at: boundArgs[14],
            expires_at: boundArgs[15],
          });
          return { meta: { changes: 1 } };
        }
        if (sql.includes('INSERT INTO handshake_requests')) {
          const id = String(boundArgs[0]);
          handshakes.set(id, {
            id,
            card_id: boundArgs[1],
            from_student_name: boundArgs[2],
            from_department: boundArgs[3],
            from_year: boundArgs[4],
            intro_note: boundArgs[5],
            sender_token_hash: boundArgs[6],
            status: 'pending',
            created_at: boundArgs[7],
            updated_at: boundArgs[7],
          });
          return { meta: { changes: 1 } };
        }
        if (sql.includes('UPDATE handshake_requests')) {
          const hs = handshakes.get(String(boundArgs[0]));
          if (hs) {
            hs.status = boundArgs[1];
            hs.updated_at = boundArgs[2];
            return { meta: { changes: 1 } };
          }
          return { meta: { changes: 0 } };
        }
        if (sql.includes('UPDATE pulse_cards') && sql.includes('spots_remaining')) {
          const card = cards.get(String(boundArgs[0]));
          if (card) {
            const nextSpots = Math.max(0, Number(card.spots_remaining) - 1);
            card.spots_remaining = nextSpots;
            if (nextSpots === 0) card.status = 'filled';
            return { meta: { changes: 1 } };
          }
          return { meta: { changes: 0 } };
        }
        return { meta: { changes: 1 } };
      },
    };
    return stmt;
  };

  return { prepare } as unknown as D1Database;
}

### Complete Setup & Deployment Documentation (`README.md`)

```markdown
# VGU Pulse (`vgu-pulse-next`) — Stage 2 Full-Stack Codebase

Student-first utility toolkit, structured collaboration request board, and campus event discovery for **Vivekananda Global University (VGU), Jaipur**.

## Architecture Overview
- **Frontend:** React 18, TypeScript, Tailwind CSS v4, Vite 6
- **Backend API & Edge HTMLRewriter:** Cloudflare Workers (`src/worker/index.ts`)
- **Database:** Cloudflare D1 SQLite (`migrations/0001_initial_schema.sql`, `migrations/0002_seed_verified_events.sql`)
- **Privacy & Security Model:**
  - **Local-First Toolkit:** Attendance calculations, SGPA/CGPA estimations, and semester planner tasks stay 100% in browser `localStorage` and work offline without any account.
  - **Capability-Token Ownership:** Publishing a card or sending a handshake returns a 256-bit cryptographic capability token stored in your browser vault; only its SHA-256 hash is stored in D1.
  - **Private Coordination Handoff:** Public cards block phone numbers and email addresses. A creator's `coordinationNote` is stored privately in D1 and revealed **only** to a requester whose handshake is explicitly accepted by the card owner.
  - **Fail-Closed Verification:** Production requires a valid Cloudflare Turnstile secret key (`TURNSTILE_SECRET_KEY`); if unconfigured in `APP_ENV="production"`, write endpoints fail closed (`503`).

---

## Environment Variables Reference

| Variable | Where Configured | Required Locally? | Required in Production? | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `APP_ENV` | `wrangler.jsonc` / `.dev.vars` | Optional (defaults to `development`) | **Yes (`production`)** | Controls fail-closed Turnstile enforcement. |
| `PUBLIC_ORIGIN` | `wrangler.jsonc` / `.dev.vars` | Optional (`http://localhost:5173`) | **Yes** | Canonical base URL for OpenGraph `/cards/:id` and `/events/:id` metadata. |
| `TURNSTILE_SITE_KEY` | `wrangler.jsonc` | Uses Cloudflare dummy test key by default | **Yes** | Public Turnstile widget site key. |
| `TURNSTILE_SECRET_KEY` | `.dev.vars` (local) / `wrangler secret put` (prod) | Optional (uses dummy test key) | **Yes (Fail-Closed)** | Server-side secret key validated against Cloudflare Turnstile `siteverify`. |
| `RATE_LIMIT_SALT` | `.dev.vars` / `wrangler secret put` | Optional | **Yes** | Secret salt used when SHA-256 hashing client IPs for hourly D1 rate limiting. |
